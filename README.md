📘 Social Media Post Management System using PostgreSQL
This project is a PostgreSQL-based database system designed to manage social media posts efficiently. It includes features like scheduling, likes/comments tracking, and post analytics. It's ideal for practicing relational schema design, SQL queries, and database normalization.

🔧 Features

User and post management
Scheduling and visibility handling
Post engagement tracking (likes/comments)

🛠️ Tech Stack
PostgreSQL
pgAdmin

📂 Structure
schema.sql – database schema
